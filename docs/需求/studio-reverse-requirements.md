# Data Aggregation Studio 当前页面反向需求规约

版本：2026-05-30
适用系统：Data Aggregation Studio Web 控制台
编写方式：基于当前路由、Vue 视图组件和浏览器实际页面可见项反向整理
适用读者：产品负责人、测试工程师、前端开发、后端开发、实施交付人员

## 1. 文档范围与判定规则

本规约描述当前 Web Studio 已呈现的功能需求。它不是未来蓝图，也不是操作手册；所有需求均来自当前页面可见内容、当前路由、按钮、筛选项、表格列、弹窗、抽屉、状态标签和页面跳转。

- 覆盖范围限定为 `data-aggregation-studio/frontend/apps/web` 的 Web 控制台。
- 公开页面覆盖登录页、注册登记页；业务页面覆盖菜单页、可路由的新建/编辑/详情/日志页。
- 可点击的按钮、Tab、步骤条、分页、更多菜单、弹窗确认按钮、抽屉按钮均作为可见点记录。
- 涉及删除、停用、下线、取消申请、终止运行的入口记录需求与确认规则，不要求本文执行破坏性操作。
- 系统按当前管理员可见范围整理；有角色限制的菜单在权限要求中注明。

## 2. 全局框架与访问控制

| 需求编号 | 可见点 | 需求描述 | 验收标准 |
| --- | --- | --- | --- |
| REQ-GLB-001 | 左侧导航 | 系统应在登录后的工作台展示七个菜单分组：工作空间、数据资产、数据采集、数据开发、数据服务、数据质量、系统管理。每个分组可展开或收起，并显示分组标题与说明。 | 管理员登录后可在侧边栏看到上述分组；无项目时业务菜单不显示并引导访问申请中心。 |
| REQ-GLB-002 | 菜单收起按钮 | 系统应提供“收起菜单/展开菜单”按钮控制侧边栏宽度。 | 点击后侧边栏状态切换，主内容区仍可正常显示。 |
| REQ-GLB-003 | 租户选择器 | 系统应在侧边栏上下文区展示租户选择器，已登录且存在租户时可切换租户。 | 切换租户后刷新项目列表；失败时给出上下文切换失败提示。 |
| REQ-GLB-004 | 项目选择器 | 系统应在侧边栏上下文区展示项目选择器，已登录且存在项目时可切换项目。 | 切换项目后页面使用新项目上下文加载数据。 |
| REQ-GLB-005 | 语言切换 | 系统应展示 English 与中文两个语言按钮，并切换界面语言。 | 点击 English/中文后菜单、标题、按钮文案切换到对应语言。 |
| REQ-GLB-006 | 站内信入口 | 系统应在主内容头部展示站内信铃铛和未读数量。 | 点击站内信入口应进入消息中心或打开消息入口；未读数量与消息接口返回一致。 |
| REQ-GLB-007 | 页面标题与副标题 | 系统应根据路由 meta 展示页面标题、副标题，并在登录后附加当前用户、租户、项目上下文。 | 每个业务页面标题与路由一致，副标题包含当前登录用户和上下文。 |
| REQ-GLB-008 | 退出登录 | 系统应提供退出登录按钮。 | 点击后清除本地 Token、用户名、租户、项目缓存，并跳转登录页。 |
| REQ-GLB-009 | 无项目访问 | 登录用户没有当前项目时，系统应隐藏需项目菜单并展示访问申请中心入口。 | 无项目上下文访问业务页面时跳转 `/access-center`。 |
| REQ-GLB-010 | 未登录访问 | 未登录访问非公开页面时，系统应跳转 `/login`。 | 清空本地 Token 后访问 `/dashboard` 跳转登录页。 |
| REQ-GLB-011 | 根路径重定向 | 访问 `/` 时系统应使用 StudioLayout 并重定向到 `/dashboard`。 | 已登录且有项目时进入总览；未登录时进入登录页。 |
| REQ-GLB-012 | 未知路径捕获 | 访问未定义路径时系统应进入全局捕获路由。 | 未登录跳转 `/login`；已登录跳转 `/dashboard`。 |
| REQ-GLB-013 | 模型统计兼容路由 | 访问 `/models/statistics` 时系统应兼容重定向到 `/statistics`。 | 地址进入后展示统计分析页。 |

## 14. 验收约束

- 任一路由新增、删除或重命名时，必须同步更新页面与路由覆盖矩阵。
- 任一页面新增按钮、筛选项、表格列、弹窗或抽屉时，必须新增对应需求编号。
- 任一按钮改变跳转、禁用条件或确认逻辑时，必须同步更新验收标准。
- 数据服务和数据接入服务的 Token、免 Token、默认订阅方、WebService、调用日志入口属于高优先级验收项。
- 采集任务、工作流、质量任务、接入服务的运行日志入口必须保证可达，并按具体运行记录隔离展示。
