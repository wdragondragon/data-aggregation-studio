# 字段映射规则模块 Web 测试用例

## 1. 测试目标

本文档用于记录 Web 端“字段映射规则”模块的基础回归与历史冒烟用例，重点覆盖：

- 页面路由与上下文展示
- 内置规则列表加载
- 分页与筛选区渲染
- 基础操作入口渲染

## 3. 用例列表

| 编号 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| FMR-UI-001 | 页面可进入 | 登录后访问 `/field-mapping-rules` | 页面标题为“字段映射规则”，当前项目上下文正常显示 |
| FMR-UI-002 | 内置规则加载 | 打开规则列表页 | 内置规则列表成功加载，能看到映射名、类型、编码、状态、创建人、创建时间 |
| FMR-UI-003 | 分页渲染 | 打开规则列表页 | 页面显示总数、每页条数、页码和下一页按钮 |
| FMR-UI-004 | 筛选区渲染 | 打开规则列表页 | 关键字、映射类型、启用状态筛选项与“查询/重置”按钮完整显示 |
| FMR-UI-005 | 基础操作入口 | 打开规则列表页 | “新建规则”“编辑”“删除”“刷新”等入口完整显示 |
| FMR-UI-006 | 浏览器稳定性 | 执行 FMR-UI-001 至 FMR-UI-005 | 浏览器控制台无 `error` / `warn`，页面无渲染异常 |

## 4. 通过标准

- FMR-UI-001 至 FMR-UI-006 全部通过。
- 至少能加载出首屏规则列表和分页信息。
- 规则列表字段不可缺失，不能出现空白页或接口失败提示。
