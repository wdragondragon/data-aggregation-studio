# 数据开发模块 Web 测试用例

## 1. 测试目标

本文档用于记录 Web 端“数据开发”模块的基础回归与历史冒烟用例，重点覆盖：

- 页面路由与当前项目上下文展示
- 空态渲染
- 目录创建
- 新建脚本编辑器基础表单加载

## 2. 测试环境

| 项目 | 说明 |
| --- | --- |
| 前端 | `http://127.0.0.1:5173` |
| Studio Server | `http://127.0.0.1:18080` |
| Studio Worker | `http://127.0.0.1:18081` |
| 数据库 | SQLite：`backend/studio-test/target/test-runtime/web-smoke.db` |
| 登录账号 | `admin / admin123` |
| 当前租户 | `Default Tenant` |
| 当前项目 | `Default Project` |

## 3. 用例列表

| 编号 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| DD-UI-001 | 页面可进入 | 登录后访问 `/data-development` | 页面标题为“数据开发”，左侧和页头均显示当前租户、项目上下文 |
| DD-UI-002 | 空态展示 | 在无目录、无脚本的初始化项目中首次进入页面 | 左侧目录树展示空态文案，编辑区提示“请先在左侧选择脚本，或在当前目录下新建一个脚本” |
| DD-UI-003 | 新建目录 | 点击“新建目录”，填写目录名称、权限编码、描述并保存 | 页面提示“目录已保存”，目录树出现新目录 |
| DD-UI-004 | 新建脚本表单 | 点击“新建脚本” | 页面展示文件名、脚本类型、数据源、脚本描述、脚本编辑器和执行结果区域 |
| DD-UI-005 | 浏览器稳定性 | 执行 DD-UI-001 至 DD-UI-004 | 浏览器控制台无 `error` / `warn`，页面无白屏或阻塞交互 |

## 4. 通过标准

- DD-UI-001 至 DD-UI-005 全部通过。
- 若项目初始化为空，空态必须可读且操作入口完整。
- 新建目录成功后，目录树必须立即反映结果。
- 新建脚本表单必须完整渲染，不允许缺少编辑区或基础字段。
