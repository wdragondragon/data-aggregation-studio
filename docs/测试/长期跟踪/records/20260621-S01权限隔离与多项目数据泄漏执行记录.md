## 代码边界

| 层 | 文件与结论 |
|---|---|
| 认证 | `AuthController`、`StudioAccessService`、`StudioSecurityService`：登录后按租户/项目头构造有效角色；禁用用户返回 `401 UNAUTHORIZED`。 |
| 角色/权限 | `RoleController`、`PermissionController`：list/save/delete 均调用 `requireSuperAdmin()`，普通成员返回 `403 FORBIDDEN`。 |
| 系统管理 | `SystemManagementController`、`SystemManagementService`：项目成员、Worker 绑定、资源共享等写入类入口经 `requireManageableProject()` 或更高角色检查。 |
| 共享资源 | `ProjectResourceAccessService`、`WorkflowService`：共享工作流可读；保存、发布、删除经 `assertWritable()` 阻止接收项目写源项目定义。 |
| 导入导出 | `ImportExportController` 调用 `workflowService.listOwnedByCurrentProject()`，接收项目导出不包含源项目共享工作流。 |
| 运行日志 | `RunController`、`RunLogProxyService`、`RunService.getEntity()`：运行详情和日志下载按当前租户/项目过滤。 |
| 调用日志 | `InvocationLogController`、`OpenServiceInvocationLogService.requirePointer()`：数据服务、接入服务、协议转换调用日志按当前租户/项目严格匹配。 |
