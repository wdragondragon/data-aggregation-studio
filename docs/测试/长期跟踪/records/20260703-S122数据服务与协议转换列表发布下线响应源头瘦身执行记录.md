## 修复摘要

- 保留原完整接口：`POST /data-services/{id}/publish`、`/offline`、`POST /protocol-conversions/{id}/publish`、`/offline`，继续服务编辑页或详情场景。
- 新增列表专用轻响应接口：`/publish-summary`、`/offline-summary`，返回列表行摘要视图。
- `DataServicesView.vue` 与 `ProtocolConversionServicesView.vue` 列表页发布/下线改用 summary 接口，动作后仍执行 `loadServices()` 重拉当前页，保持分页、排序和状态补位可信。
- 后端列表查询抽出 `selectTableListColumns()`，summary 响应只按表格展示字段查询，不读取自定义 SQL、参数、WebService 配置、字段映射、转换器、目标模板等详情字段。
- 发布/下线写状态改为 `LambdaUpdateWrapper` 显式 set 状态、更新时间、服务 key 和发布地址，避免整实体 `updateById` 回写详情配置。
- `DataServiceListView` 与 `ProtocolConversionServiceListView` 增加非空字段序列化约束，防止轻量查询未读取的详情字段以 `null` 形式出现在响应中。
