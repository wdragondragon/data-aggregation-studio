## 修复记录

### BUG-M03-001 切换到已保存 Java/Python 脚本时内容被默认模板覆盖

现象：

- 从 SQL 脚本切换到已保存的 Java 脚本时，编辑器显示 `DemoJavaDataScript` 默认模板。
- UI 执行结果为 `Java script executed successfully`，而不是保存脚本里的 `长期回归 Java 客户分析完成`。
- Python 脚本存在同类风险。

根因：

- `DataDevelopmentView.vue` 的 `scriptForm.scriptType` watcher 在 `previousType === "SQL"` 时会覆盖 Java/Python 内容。
- 加载已保存脚本时，先写入 `scriptType`，watcher 触发后把内容替换成默认模板，随后异步加载过程不能稳定保留服务端内容。

修复：

- 文件：`frontend/apps/web/src/views/DataDevelopmentView.vue`
- 只在 `scriptForm.content` 为空时自动填充 Java/Python 模板，不再依据 `previousType === "SQL"` 强制覆盖。

回归：

- 已保存 Java 脚本加载后显示 `LongTermCustomerAnalysisScript` 和中文日志/消息。
- 已保存 Python 脚本加载后显示 `长期回归 Python 脚本开始执行`。
- 空白新脚本切换 Java 仍自动填充默认模板。
