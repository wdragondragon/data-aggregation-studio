## 问题确认

| 编号 | 模块 | 现象 | 真实存在 | 是否需要修复 |
|---|---|---|---|---|
| S89-PC-001 | 协议转换/服务列表 | `ProtocolConversionService.list()` 的 `.select(...)` 包含 `tenantId/deleted/createdBy/tokenRequired/defaultSubscriptionName/sourceMethod/sourceDataNodePath/targetDatasourceId/targetMethod/payloadMode` 等表格不展示字段 | 是 | 是 |
| S89-PC-002 | 协议转换/列表写后刷新 | 列表页删除服务后直接调用 `loadServices()` 重拉整个列表 | 是 | 是 |

根因：

- 早期 `ProtocolConversionServiceListView` 同时承载了列表行和部分详情基础字段，列表源查询按“可供后续操作 patch”的思路保留了过多字段。
- 删除动作没有沿用其他列表页已经采用的“本地移除，页空再补拉”的刷新收敛模式。
