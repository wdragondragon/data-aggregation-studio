## 修复记录

### BUG-M04-001 列表页点击调试未直接进入接口调试步骤

现象：

- 数据服务列表点击 `调试` 会跳转到 `/data-services/{id}/edit?debug=1`。
- 编辑页原逻辑只加载服务详情，未消费 `debug=1`，停留在第 1 步基础信息。

根因：

- `DataServiceEditorView.vue` 的初始化流程没有根据 `route.query.debug` 切换 `activeStep`。

修复：

- 文件：`frontend/apps/web/src/views/DataServiceEditorView.vue`
- 在 `loadInitialData()` 完成服务详情、数据源和模型加载后，若存在 `route.query.debug`：
  - 设置 `activeStep.value = wizardSteps.length - 1`
  - 调用 `syncDebugTemplate({ notify: false })`

回归：

- 浏览器访问 `/data-services/2068117382314565633/edit?debug=1`。
- 页面最终第 4 步 `接口调试` 处于 active，显示 `发送调试`、`生成 cURL`。
- 初始加载期间会短暂显示基础信息和 `加载中`，数据加载结束后自动切换到调试页，判定为 PASS。

### BUG-M04-002 免 Token WebService 样例仍生成假 token，导致按样例调用失败

现象：

- `长期回归-客户订单查询服务` 设置 `tokenRequired=false` 且启用 WebService。
- WebService 预览样例仍生成 SOAP Header token 占位，例如 `your-token`。
- 开放 SOAP 调用逻辑优先读取 SOAP Header token，因此带假 token 的样例会返回 `401`。
- 手动移除 SOAP Header 后调用可成功。

根因：

- `WebServiceSupport.sampleRequest(...)` 未区分服务是否要求 Token，默认生成 Token Header。

修复：

- 文件：`backend/studio-infra/src/main/java/com/jdragon/studio/infra/service/WebServiceSupport.java`
- `sampleRequest(...)` 增加 `includeTokenHeader` 参数。
- `previewForDataService(...)` 和 `previewForDataIngestion(...)` 按 `tokenRequired` 决定是否生成 SOAP Header。
- 默认行为保持保守：未显式设置 `Boolean.FALSE` 时仍按需要 Token 处理。

回归：

- `GET /api/v1/data-services/2068117382251651073/webservice/preview`
- 结果：`sampleRequest` 不包含 `your-token`、`soap:Header`、`dataServiceToken`。
- 使用预览样例通过网关调用：
  `http://127.0.0.1:8000/dfs/data-aggregation-studio/openapi/ws/data-services/lt_reg_customer_order_query_api/ZsVjA0yVWCce3VI9`
- 结果：HTTP `200`，响应包含 `queryCustomerOrdersResponse`，不包含 `Fault`。
