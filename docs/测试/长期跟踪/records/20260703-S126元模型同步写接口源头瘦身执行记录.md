## 修复摘要

- 保留原完整接口：
  - `POST /meta-schemas/technical/sync/{typeCode}`
  - `POST /meta-schemas/technical/sync-all`
- 新增页面专用 summary 接口：
  - `POST /meta-schemas/technical/sync/{typeCode}/summary`
  - `POST /meta-schemas/technical/sync-all/summary`
- `/metadata` 前端同步按钮改用 summary 接口；同步后只合并 schema 摘要，当前选中叶子需要预览时仍通过 `GET /meta-schemas/{schemaId}` 按 id 获取详情。
- `MetadataSchemaService.findTechnicalMetaModel()` 改为按标准 `schemaCode=technical:{typeCode}:{metaModelCode}` 直接查询目标 schema，再只读取该目标 schema 的字段用于刷新判定，不再加载全部元模型字段。
- 新增回归测试：
  - `MetadataSchemaSourceSlimmingRegressionTest`
  - `StudioInitializationApiRegressionTest#metadataSchemasShouldContainRequiredMysqlTechnicalMetaModelsAndFieldDefinitions` 增加 summary 同步响应字段为空断言。
