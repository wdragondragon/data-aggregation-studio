# S55 脚本环境下拉源头瘦身与依赖选项懒加载执行记录

## 背景

- 日期：2026-06-28
- 入口：`http://127.0.0.1:8000/dfs/data-aggregation-studio`
- 账号：`admin / admin123`
- 长期项目：`长期回归测试项目`，项目 ID `2068077680446365698`
- 目标：继续排查前端可达页面中过度获取数据的接口，重点复核数据开发 Java 脚本运行环境下拉和脚本环境管理页的依赖包选项加载。

## 发现的问题

1. `/script-environments/options` 是运行环境下拉接口，但返回 `ScriptEnvironmentView`，前端只需要 `id/environmentName/environmentCode/enabled`，旧接口还读取/返回描述、运行环境版本、依赖 ID 和依赖列表等详情字段。
2. `ScriptEnvironmentsView` 首屏会同时加载环境列表、依赖列表和依赖选项；依赖选项只在新建/编辑运行环境弹窗里使用，不应在页面首屏加载。
3. `/environment-dependencies/options` 虽是依赖包下拉接口，但源头未显式 select 选项字段，存在读取 artifact、checksum、description 等详情字段的风险。

## 本轮整改

- 新增 `ScriptEnvironmentOptionView`，`/script-environments/options` 改为返回轻量选项。
- `ScriptEnvironmentService.options()` 源头只 select `id/tenantId/deleted/createdAt/updatedAt/environmentName/environmentCode/enabled`。
- `EnvironmentDependencyService.options()` 源头只 select `id/tenantId/deleted/createdAt/updatedAt/name/version/scriptType/enabled`。
- `DataDevelopmentView` 的 Java 运行环境下拉改用 `ScriptEnvironmentOption` 类型。
- `ScriptEnvironmentsView` 将依赖选项改为打开运行环境弹窗时懒加载，首屏不再拉 `/environment-dependencies/options`。
- 新增 `ScriptEnvironmentOptionsSourceSlimmingRegressionTest` 覆盖两个下拉接口的 select 字段。
