## 非阻断观察

- `/notifications` 控制台仍有 Element Plus 分页废弃 API warning：`[ElPagination] 你使用了一些已被废弃的用法`。当前不影响渲染、筛选、已读操作和构建，按长期计划中的可暂缓项记录。
- Maven 回归中 Redis cache 不可用会降级到本地内存 fallback，测试结果不受影响。
- Maven 回归结束后偶发 legacy Nacos listener WARN；运行态复查 Server/Worker health 均为 `UP`。
- 管理员登录返回的默认项目仍是 `2047489207831650317`，本轮实服 API 测试显式传入 `X-Project-Id=2068077680446365698` 或接收项目 ID，保证测试上下文正确。

## 结论

M10 通知、关注、导入导出与日志下载模块本轮发现 1 个真实高风险问题：项目导出包含跨项目共享工作流。已完成后端修复、补充回归测试，并通过 Maven 回归、前端构建、实服 API 和浏览器通知页验证。长期测试数据全部保留，可用于后续导出隔离、关注状态、通知未读数和日志下载的快速迭代回归。
