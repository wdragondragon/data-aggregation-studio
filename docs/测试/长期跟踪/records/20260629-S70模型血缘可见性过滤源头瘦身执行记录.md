## 发现的问题

模型详情血缘 Tab 通过以下接口加载血缘图和边详情：

- `GET /api/v1/models/{id}/lineage?level=DATABASE|TABLE|FIELD`
- `GET /api/v1/models/{id}/lineage/edges/{edgeId}`

代码复核确认：

- 焦点模型在血缘图和边详情中只需要 `id/tenantId/projectId/deleted/datasourceId/name/physicalLocator`。
- 可见性过滤只需要可读模型 ID、数据源 ID。
- 焦点数据源只需要 `id/name/typeCode/technicalMetadata` 用于展示库级节点摘要。

修复前这些路径复用完整实体读取，可能额外读取 `schemaVersionId/technicalMetadata/businessMetadata/connectionFingerprint` 等大字段，违反“从源头轻量，不获取完整数据再组合轻视图”的约定。

## 本轮整改

1. 血缘焦点模型改为轻量读取
   - `getModelLineage()`、`getEdgeDetail()` 改用 `requireReadableLineageModel()`。
   - 只 select 血缘图需要的模型摘要列。

2. 血缘焦点数据源改为轻量读取
   - `DataModelLineageService.loadLineageFocusDatasource()` 只读取血缘节点展示所需列。
   - `DataModelLineageGraphAssembler.buildContext()` 不再 `selectById()` 读取完整数据源，改用轻量查询。

3. 可见性过滤改为只查 ID
   - `visibleModelIds()` 只 select `id`。
   - `visibleDatasourceIds()` 只 select `id`。

4. 保留完整模型详情读取路径
   - `requireReadableModel()` 继续保留给字段校验、手工字段血缘等确实需要模型技术元数据的路径使用。
