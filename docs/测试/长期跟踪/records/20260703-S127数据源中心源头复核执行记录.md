## 代码复核摘要

- `DatasourcesView.vue`
  - `loadPage()` 初始加载：`datasources.listPage()`、`metaSchemas.list({ includeFields: false })`、`catalog.capabilities()`。
  - `handleDatasourcePageChange()` / `handleDatasourcePageSizeChange()` 只调用 `loadDatasources()`，属于分页当前页读取。
  - `editDatasource()` 通过 `GET /datasources/{id}` 按 id 下钻详情。
  - `ensureDatasourceSchemaDetails()` 只对当前类型候选 schema 补字段详情。
  - `discoverModels()` 调用 `discoverOptions()`。
  - `testDatasource()` 仅把连接测试结果 patch 到当前行。
  - `openConnectionHistory()` 只在用户点击连接趋势后读取 7 天历史。
- `DataSourceService`
  - `listSummaryPage()` 使用 `selectSummaryColumns()`，不读取 `technicalMetadata/businessMetadata`。
  - `listBasicOptions()` 使用 `selectOptionColumns()`，不读取连接健康、技术元数据和业务元数据。
  - `hydrateListViews()` 对列表健康状态只读取健康摘要和连接趋势点。
  - `discoverModelOptions()` 保留轻量发现路径，完整 `discoverModels()` 继续保留给兼容调用。
