## 问题确认

| 编号 | 模块 | 现象 | 真实存在 | 是否需要修复 |
|---|---|---|---|---|
| S97-QM-001 | 质量指标/模型筛选下拉 | `DataModelService.listMetricFilterOptionPage(datasourceId, ...)` 只需要校验 datasourceId 可读，却调用 `dataSourceService.get(datasourceId)`，导致完整读取数据源详情、连接元数据和健康水合 | 是 | 是 |

根因：

- S56 已将质量指标模型筛选改为分页轻量接口，模型列表本身只 select `id/name/physicalLocator`。
- 但 datasourceId 校验沿用了详情入口 `dataSourceService.get()`。
- `get()` 会按 id 读取完整数据源实体，并组装 `DataSourceDefinition`、脱敏技术元数据、补充连接健康信息；筛选下拉只需要确认当前用户可读该数据源。
