## 真实缺陷

### BUG-S22-001 前端不可读直达页错误态不完整

- 严重级别：中
- 影响范围：采集任务、数据服务、数据接入、协议转换、质量规则、质量任务、工作流编辑/详情、工作流运行详情。
- 复现摘要：访问不存在或当前项目不可读的编辑/详情 URL，接口失败前页面可能短暂或持续展示空表单/写操作入口。
- 根因：多个编辑/详情页面只处理加载失败提示，未把详情缺失作为独立不可用态统一阻断表单和 toolbar 写入口。
- 修复文件：`CollectionTaskEditorView.vue`、`DataServiceEditorView.vue`、`DataIngestionServiceEditorView.vue`、`ProtocolConversionServiceEditorView.vue`、`QualityRuleEditorView.vue`、`QualityTaskEditorView.vue`、`WorkflowEditorView.vue`、`WorkflowDetailView.vue`、`WorkflowRunDetailView.vue`、`frontend/packages/i18n/src/messages/web.ts`。
- 回归证据：S22-UI-001 至 S22-UI-009 全部 PASS。

### BUG-S22-002 工作流详情缺失对象接口返回成功空数据

- 严重级别：中
- 影响范围：`GET /api/v1/workflows/{id}`、工作流详情直达页、前端错误态判定。
- 复现摘要：运行中服务请求 `/workflows/999999999999999999` 返回 `HTTP 200 / SUCCESS / data:null`，与其他详情接口的 `404 NOT_FOUND` 契约不一致。
- 根因：`WorkflowService.get` 在 `findAccessibleEntity` 返回 `null` 时直接返回 `null`。
- 修复文件：`backend/studio-infra/src/main/java/com/jdragon/studio/infra/service/WorkflowService.java`、`backend/studio-infra/src/test/java/com/jdragon/studio/infra/service/WorkflowServiceRegressionTest.java`、`backend/studio-infra/pom.xml`。
- 回归证据：`mvn -pl studio-infra -am -Dtest=WorkflowServiceRegressionTest "-Dsurefire.failIfNoSpecifiedTests=false" test` 通过，`Tests run: 1, Failures: 0, Errors: 0`。
- 剩余验证：当前 Server 进程未加载新代码，实服 HTTP 仍是旧行为；需重启 `StudioServerApplication` 后复查 `/api/v1/workflows/999999999999999999`。

### BUG-S22-003 Cron 组件触发 Element Plus `type.text` 弃用告警

- 严重级别：低
- 影响范围：采集任务、质量任务、工作流等含 CronExpressionPicker 的页面。
- 复现摘要：打开含 Cron 组件页面，console 出现 `ElementPlusError: [props] [API] type.text is about to be deprecated...`。
- 根因：第三方 `no-vue3-cron` 内部语言切换按钮使用 `el-button type="text"`；该按钮虽被 CSS 隐藏，但仍会被渲染并触发 Element Plus deprecation watcher。
- 修复文件：`frontend/apps/web/vite.config.ts`，构建阶段仅对 `no-vue3-cron/lib/noVue3Cron.*` 做窄范围替换，把隐藏语言按钮从 `type: "text"` 改为 `link: true`。
- 回归证据：`npm run build` 通过；最新 `CronExpressionPicker-*.js` 中 `class:"language",type:"text"` 为 `False`、`class:"language",link:!0` 为 `True`；9 页浏览器复验 console warn/error 为 0。
