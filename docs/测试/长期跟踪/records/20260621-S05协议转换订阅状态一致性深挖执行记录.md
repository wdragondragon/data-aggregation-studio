## 修复摘要

- `ProtocolConversionService.enableSubscription` 增加同名启用订阅查询：
  - 条件：同一 `serviceId`、同一 `subscriptionName`、`enabled=1`、排除当前订阅。
  - 命中时抛出 `BAD_REQUEST`：`Another enabled subscription with the same name already exists`。
- `SubscriptionTokenRotationRegressionTest` 新增协议转换订阅启用重名防护用例。
