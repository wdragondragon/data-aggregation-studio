# S72 脚本环境 Tab 按需加载与刷新收敛执行记录

- 账号：`admin / admin123`

- 目标：继续深挖当前页面是否存在“不可见表格提前取数”和“刷新范围过大”的问题。

## 发现的问题

`ScriptEnvironmentsView.vue` 默认打开 `依赖包` Tab，但页面初始化时执行 `refreshAll()`，同时触发：

```ts
Promise.all([
  loadDependencies(),
  loadEnvironments(),
])
```

实际首屏只展示依赖包表格，运行环境表格需要用户切换到 `运行环境` Tab 后才可见。后端 `script-environments/queryPage` 是运行环境表格分页接口，并且会额外读取当前页运行环境关联的依赖选项；该数据不是依赖包 Tab 的前置数据。

同一顶部 `刷新` 按钮也会同时刷新依赖包和运行环境两个表格，导致当前只查看一个 Tab 时刷新不可见表格。

## 本轮整改

1. Tab 表格改为按需加载
   - 新增 `loadedTabs` 记录 `dependencies` 与 `environments` 是否已成功加载。
   - 首屏只加载当前激活的 `依赖包` Tab。
   - 切换到 `运行环境` Tab 时首次加载运行环境表格。
   - 已加载 Tab 再次切回时复用当前数据，避免无意义重复请求。

2. 顶部刷新范围收敛
   - `刷新` 只强制刷新当前激活 Tab。
   - 若依赖包选项缓存已被运行环境弹窗加载，刷新依赖包 Tab 时同步刷新该同域选项缓存。

3. 保持已有写后局部更新
   - 依赖包保存、启停、删除继续局部 upsert/remove 当前表格行。
   - 运行环境保存、启停、刷新缓存继续局部 upsert 当前表格行。
   - 运行环境弹窗依赖包选项继续懒加载，不回退到首屏预取。
