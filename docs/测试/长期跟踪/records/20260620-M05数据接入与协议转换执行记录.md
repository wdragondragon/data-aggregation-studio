## 修复记录

### BUG-M05-001 MySQL writer 默认 insert 模式实际表现为 upsert

现象：

- 数据接入服务默认 `writeMode=insert`。
- 对相同 `ingest_id` 重复写入时，第二次没有因主键冲突失败，而是触发 `ON DUPLICATE KEY UPDATE` 覆盖了原记录。
- 运行态复现样例：`M05DUP0620091258` 第二次写入把 `tag_value` 覆盖为 `重复写入应失败`。

根因：

- `CommonRdbmsWriter.calcWriteRecordSql()` 对 MySQL/Mysql8 调用 `WriterUtil.getWriteTemplate(...)` 时强制走重复键更新模板，忽略了实际 `writeMode`。

修复：

- 文件：`DataAggregation/job-plugins/utils/plugin-rdbms-util/src/main/java/com/jdragon/aggregation/rdbms/writer/CommonRdbmsWriter.java`
- 调整 MySQL 写入模板生成逻辑，默认 `insert` 不再拼接 `ON DUPLICATE KEY UPDATE`。
- 文件：`DataAggregation/job-plugins/utils/plugin-rdbms-util/pom.xml`
- 新增测试依赖：JUnit 4.13.2 和 test-scope `data-source-handler-mysql8`。
- 文件：`DataAggregation/job-plugins/utils/plugin-rdbms-util/src/test/java/com/jdragon/aggregation/rdbms/util/WriterUtilTest.java`
- 覆盖 MySQL `insert`、`update`、`replace` 三种写入模板。

回归：

```powershell
cd C:\dev\ideaProject\cloud-parent-springboot3\DataAggregation
$env:JAVA_HOME='C:\dev\Java\jdk-17.0.12'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
mvn -pl job-plugins/utils/plugin-rdbms-util -am -Dtest=WriterUtilTest -DfailIfNoTests=false test
mvn -pl job-plugins/writer/mysql8writer -am -DskipTests package
```

结果：

- `WriterUtilTest` 共 3 个测试通过。
- 重新构建并复制 `mysql8writer` 到本地 `package_all/aggregation/plugin/writer/mysql8writer`。
- 运行态复测 `M05DUP0620091956`：首次写入成功，第二次返回主键重复错误，数据库保留首次值 `tag_value='首次写入'`。

### BUG-M05-002 数据接入写入失败时开放 API 暴露 Java 堆栈和内部路径

现象：

- 修复 BUG-M05-001 后，重复主键会正确失败。
- 但开放 API 的失败响应暴露了 Java stack trace、内部类名和本地路径。

根因：

- `DataIngestionExecutionSupport` 直接透传底层异常文本，未对聚合框架异常做用户级脱敏。

修复：

- 文件：`DataAggregation/data-aggregation-studio/backend/studio-infra/src/main/java/com/jdragon/studio/infra/service/DataIngestionExecutionSupport.java`
- 新增 `safeFailureMessage(...)`，优先提取最深层 root cause，移除 stack frame / class prefix，最大保留 500 字符。
- 文件：`DataAggregation/data-aggregation-studio/backend/studio-test/src/test/java/com/jdragon/studio/infra/service/DataIngestionInvocationLogSupportTest.java`
- 新增 root cause 脱敏和扁平堆栈脱敏测试。

回归：
