## 复现与代码确认

### 复现结果

- 复现批次：`20260622013023`
- SOAP Trace：`LT-S15-SOAP-20260622013023`
- 订阅：`2068748401933733890`
- 访问日志：`2068748407751233538`
- 复现路径：
  1. 创建/发布 SOAP 源协议转换服务，目标仍转发到 `/actuator/health`。
  2. 创建中文命名订阅。
  3. 通过 `/openapi/ws/protocol-conversions/{serviceCode}/{serviceKey}` 发起 SOAP 调用，订阅 token 放在 SOAP Header。
  4. SOAP Envelope 中加入敏感 XML 元素和属性：`protocolConversionToken`、`clientSecret`、`password`、`apiKey`。
  5. 下载协议转换完整日志并检索本批次原文。
- 实际：完整日志中泄露以下原文类型：
  - `LT-S15-RAW-SOAP-TOKEN-*`
  - `LT-S15-RAW-SOAP-PASSWORD-*`
  - `LT-S15-RAW-SOAP-APIKEY-*`
  - 订阅 token 原文
- 结论：真实缺陷。

### 根因

- `OpenServiceInvocationLogSupport#sanitizeSensitiveLog` 只覆盖 JSON 字段值和 `key=value`/`key:value` 赋值格式。
- SOAP/XML 中的敏感元素值 `<password>...</password>`、`<apiKey>...</apiKey>`、`<tns:protocolConversionToken>...</tns:protocolConversionToken>` 以及敏感属性 `apiKey="..."` 未被遮蔽。
- 该工具被协议转换 Trace 预览、完整日志归档、日志查看/下载共用，因此影响数据服务、数据接入、协议转换所有开放调用日志的 XML/SOAP 场景。
