## 本轮整改

1. 字段映射规则列表
   - `GET /field-mapping-rules` 改为 `FieldMappingRuleListView`。
   - 列表查询源头只选表格需要的规则名称、类型、编码、状态、创建人、时间等字段。
   - 详情 `/field-mapping-rules/{id}` 与选项 `/field-mapping-rules/options` 保留完整参数定义，供编辑器与转换器绑定使用。
   - 删除规则后前端本地移除当前行，不再整页刷新。

2. 数据开发脚本列表与树
   - `GET /data-development/scripts` 改为 `DataDevelopmentScriptListView`，不返回 `content`。
   - `/data-development/tree` 的脚本查询源头也排除 `content`。
   - 脚本正文只在 `/data-development/scripts/{id}` 详情和工作流脚本预览时按 id 获取。
   - 数据源名称/类型改为批量读取基础摘要，避免脚本列表间接拉完整数据源技术/业务元数据。

3. 运行环境依赖包列表
   - `POST /environment-dependencies/queryPage` 改为 `EnvironmentDependencyListView`。
   - 依赖包查询源头排除 `description`、`checksum` 等详情字段；文件摘要查询只取文件名、类型、大小、可见/启用状态。
   - 编辑依赖包时按 id 获取完整详情。
   - 保存、启停、删文件后只更新当前依赖包行、依赖选项缓存和相关运行环境引用。

4. 脚本运行环境列表
   - `POST /script-environments/queryPage` 改为 `ScriptEnvironmentListView`。
   - 运行环境列表源头排除 `description`；关联依赖批量查询轻量 option，不再取完整依赖对象和文件。
   - 编辑运行环境时按 id 获取完整详情。
   - 保存、启停、刷新环境缓存后只更新当前运行环境行。

## 保留风险

- 依赖包/运行环境列表的关键字筛选仍支持后端按 `description` 命中；前端局部更新时列表行不持有 `description`，因此在“当前筛选关键字只命中描述”的极小场景，局部行判断可能无法精准补入新行。当前处理选择不重载整页，必要时后续可拆一个窄范围的表格查询刷新。
