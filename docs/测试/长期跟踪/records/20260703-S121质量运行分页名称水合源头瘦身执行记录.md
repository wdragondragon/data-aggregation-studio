## 问题确认

| 编号 | 问题 | 证据 | 是否需要修复 |
|---|---|---|---|
| FIX-S121-001 | `/runs/page` 用于 `/quality-task-runs` 时，质量运行表格只展示质量任务名，却同时加载项目内采集任务名和工作流名；用于 `/collection-task-runs` 时也会加载质量任务名和工作流名。字段级 select 已经轻量，但名称水合在数量维度仍过取。 | `QualityTaskRunsView.vue` 只展示 `qualityTaskName`；`CollectionTaskRunsView.vue` 只展示 `collectionTaskName`；旧 `RunService.listRunRecords()` 无论页面类型都调用 `collectionTaskNames()`、`qualityTaskNames()`、`workflowNames()`。 | 是 |

## 修复范围

| 文件 | 修改 |
|---|---|
| `CollectionTaskService.java` | 新增 `listAccessibleNamesByIds(Collection<Long>)`，只按传入 id 批量读取 `id/name`。 |
| `QualityTaskService.java` | 新增 `listAccessibleNamesByIds(Collection<Long>)`，只按传入 id 批量读取 `id/taskName`。 |
| `RunService.java` | `listRunRecords()` 先取当前页运行记录，再按当前页实际出现的 id 水合名称；`collectionTaskOnly=true` 时只查采集任务名，`qualityTaskOnly=true` 时只查质量任务名，跳过无关工作流名。 |
| `RunListSourceSlimmingRegressionTest.java` | 新增质量运行分页只水合质量任务名断言；更新采集运行分页只水合采集任务名断言。 |
| `CollectionTaskListSourceSlimmingRegressionTest.java` | 覆盖按 id 批量查询采集任务名的轻量字段 select。 |
| `QualityListSourceSlimmingRegressionTest.java` | 覆盖按 id 批量查询质量任务名的轻量字段 select。 |
