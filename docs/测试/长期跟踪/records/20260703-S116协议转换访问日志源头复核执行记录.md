## 复核范围

| 范围 | 结论 |
|---|---|
| 协议转换日志筛选选项 | `ProtocolConversionMetricsService.options()` 只读取服务和订阅下拉所需字段；未读取协议转换完整定义、模板、桥接配置或订阅 token hash。 |
| 协议转换访问日志列表 | `queryAccessLogs()` 使用 `accessLogListQuery()` 字段级 `select`，只覆盖表格和详情抽屉复用字段，不读取 `systemLog/logObjectBucket/logObjectKey/logArchiveError` 等完整日志或对象归档字段。 |
| 四阶段 Trace 详情 | `accessLogTrace()` 通过 `requireReadableAccessLogSummary()` 做轻量摘要查询，再按 id 读取完整日志解析 Trace；历史兜底只使用摘要字段，不调用 `selectById` 整行读取。 |
| 完整调用日志抽屉 | `InvocationLogDrawer` 通过独立 `/invocation-logs/protocol-conversions/{id}` 链路读取完整日志；后端先读取日志指针字段，历史兜底才读取 `systemLog/logArchiveError`。 |
| 前端访问行为 | `/protocol-conversions/access-logs` 从 build-nginx 入口访问；页面当前项目上下文正确，console warn/error 为 0。 |
