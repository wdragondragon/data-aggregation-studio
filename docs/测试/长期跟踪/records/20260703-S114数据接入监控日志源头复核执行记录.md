## 复核范围

| 范围 | 结论 |
|---|---|
| 数据接入监控筛选选项 | `DataIngestionMetricsService.options()` 只读取服务和订阅下拉所需字段；未读取 `fieldMappings/sourceBindings/writerOptions/webserviceConfig` 或订阅 token hash。 |
| 数据接入监控 dashboard | `queryDashboard()` 走 `selectDashboardSummary/selectDashboardBuckets/selectDashboardApiStats/selectDashboardSubscriptionRank` 聚合 SQL；既有回归断言不调用日志整表 `selectList`。 |
| 数据接入 API 统计分页 | `queryApiStats()` 走 `countApiStats/selectApiStatsPage`，属于正常分页聚合读取。 |
| 数据接入访问日志列表 | `queryAccessLogs()` 使用 `accessLogListQuery()` 字段级 `select`，不读取 `systemLog/logObjectBucket/logObjectKey/logArchiveError` 等完整日志或对象归档字段。 |
| 完整调用日志抽屉 | `OpenServiceInvocationLogService` 对数据接入域先读取日志指针字段；仅在对象归档不可用时第二次读取 `systemLog/logArchiveError` 作为历史兜底。 |
| 前端访问行为 | `/data-ingestion-metrics` 与 `/data-ingestion-metrics/access-logs` 均从 build-nginx 入口访问；页面当前项目上下文正确，console warn/error 为 0。 |
