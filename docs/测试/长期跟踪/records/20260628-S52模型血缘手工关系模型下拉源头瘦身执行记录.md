## 发现的问题

`ModelLineagePanel.vue` 的手工血缘关系弹窗只需要源/目标模型的 `id/name` 用于选择标签，但原实现调用：

- `GET /models/summaries?pageNo=1&pageSize=5000`

该接口返回 `DataModelListView`，包含表格摘要字段 `datasourceId/modelKind/physicalLocator/schemaVersionId` 等。字段映射下钻已经在选中模型后调用 `GET /models/{id}` 获取详情，因此下拉不需要批量读取表格摘要字段。

旧表格摘要接口仍适合模型列表页使用，本轮不改变原接口语义，新增简单选项接口替代弹窗调用。

## 本轮整改

1. 新增轻量 DTO 和接口
   - `DataModelOptionView`
   - `GET /api/v1/models/options`

2. 源头查询约束
   - `DataModelService.listOptions(keyword, pageNo, pageSize)` 只 select `id/tenantId/projectId/deleted/createdAt/updatedAt/name`。
   - 不读取 `datasource_id/model_kind/physical_locator/schema_version_id/technical_metadata/business_metadata`。

3. 前端调用调整
   - `ModelLineagePanel.vue` 手工关系源/目标模型下拉改为远程搜索。
   - 首次加载和搜索默认 `pageSize=50`。
   - 编辑已有关系时通过 `GET /models/{id}` 确保选中项标签和字段下钻仍可用。
