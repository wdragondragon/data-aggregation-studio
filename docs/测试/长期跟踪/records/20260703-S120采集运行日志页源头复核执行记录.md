## 复核范围

| 范围 | 结论 |
|---|---|
| 页面首屏 | `CollectionTaskRunsView.vue` 首屏并行加载 `collectionTasks.options()` 和 `runs.listPage()`；前者用于筛选下拉和关注按钮前置，后者用于当前页表格与统计卡片。 |
| 采集任务筛选下拉 | `/collection-tasks/options` 只读取 `id/projectId/name`，未读取 `sourceBindingsJson/targetBindingJson/fieldMappingsJson/executionOptionsJson`。 |
| 运行记录表格 | `/runs/page` 走 `selectPage` 当前页分页，并通过 `count` 查询失败/运行中/成功统计；运行记录查询字段级 `select`，未读取 `payload_json/result_json/log_file_path/log_object_key/log_chunk_count`。 |
| 日志抽屉摘要 | 点击“查看日志”后才调用 `/runs/{id}/summary`，摘要接口按 id 读取表格/抽屉展示字段，不读取 `payload_json/result_json/log_*`。 |
| 日志内容 | 抽屉日志内容通过 `/runs/{id}/log?pageSizeBytes=65536` 分页读取，完整下载通过 `/runs/{id}/log/download` 独立触发；不压到表格接口。 |
| 刷新范围 | 顶部刷新调用当前筛选条件下的 `runs.listPage()` 当前页；分页切换和 pageSize 切换只重拉当前页；日志抽屉刷新只重拉当前日志页。 |
| build-nginx 页面 | `/collection-task-runs` 显示长期项目上下文、当前页 10 条、分页和统计卡片；打开第一条日志抽屉显示摘要与日志入口，console warn/error 为 0。 |
