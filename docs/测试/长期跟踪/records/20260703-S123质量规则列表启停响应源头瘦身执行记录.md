## 修复摘要

- 保留原完整接口：`POST /quality-rules/{id}/enable`、`POST /quality-rules/{id}/disable`，继续兼容需要完整规则视图的调用方。
- 新增列表专用接口：`POST /quality-rules/{id}/enable-summary`、`POST /quality-rules/{id}/disable-summary`，返回 `QualityRuleListView`。
- `QualityRulesView.vue` 列表启用/停用改用 summary 接口，动作成功后重拉当前筛选条件下的当前页，保持分页、排序和状态补位可信。
- 后端 summary 路径使用轻量引用查询做权限校验，只取 `id/tenantId/projectId/scopeType`；状态更新使用 `LambdaUpdateWrapper` 显式 set `enabled/updatedAt`；返回列表行只查询列表字段。
- 原完整启停接口内部也改为轻量状态更新后再按原语义返回完整详情，避免写状态时整实体回写。
