## 修复摘要

- 保留处置接口原响应契约：写入后仍返回 `QualityIssueDetailView`，供详情抽屉刷新当前详情和时间线。
- `assign`、`addComment` 写前只读取 `id/tenantId/projectId`。
- `updateStatus` 写前只读取 `id/tenantId/projectId/status/severity/reopenCount`。
- `updateSeverity` 写前只读取 `id/tenantId/projectId/status/severity`。
- 负责人、状态、严重级别更新改为 `LambdaUpdateWrapper` 显式 set 变更字段和 `updatedAt`，不再使用 `updateById` 整实体回写。
