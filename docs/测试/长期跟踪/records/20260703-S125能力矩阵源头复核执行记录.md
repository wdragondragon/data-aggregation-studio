## 代码复核

- 前端页面：`frontend/apps/web/src/views/CatalogView.vue`
  - `onMounted(loadCatalog)` 和刷新按钮均只调用 `studioApi.catalog.capabilities()`。
  - 表格使用 `sourceCapabilities` 的 `typeName/typeCode/sourceCategory/readable/writable/executable/readerPlugins/writerPlugins`。
  - 顶部统计使用 `sourceCapabilities` 和 `executableDatasourceTypes`。
- API SDK：`frontend/packages/api-sdk/src/client.ts`
  - `/catalog` 页面走 `GET /catalog/capabilities`，未额外调用运行参数 schema 或数据源类型详情。
- 后端入口：`backend/studio-server/src/main/java/com/jdragon/studio/server/web/controller/CatalogController.java`
  - `capabilityMatrix()` 返回 `executableSourceTypes`、`executableTargetTypes`、`executableDatasourceTypes`、`sourceCapabilities`，均为页面当前可见区域所需。
- 后端服务：`backend/studio-infra/src/main/java/com/jdragon/studio/infra/service/DatasourceTypeCapabilityService.java`
  - 能力配置查询已使用显式列选择，不读取不存在于能力表外的业务详情。
  - `sourceCapabilities()` 对外只返回矩阵行字段，不返回 `id/tenantId/createdAt/updatedAt/description`。
