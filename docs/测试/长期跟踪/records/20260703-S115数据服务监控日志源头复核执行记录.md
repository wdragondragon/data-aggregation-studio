| 范围 | 结论 |
|---|---|
| 数据服务监控筛选选项 | `DataServiceMetricsService.options()` 只读取服务和订阅下拉所需字段；未读取数据服务完整定义、请求参数、响应参数、脚本配置或订阅 token hash。 |
| 数据服务监控 dashboard | `queryDashboard()` 走 `selectDashboardSummary/selectDashboardBuckets/selectDashboardApiStats/selectDashboardSubscriptionRank` 聚合 SQL；既有回归断言不调用日志整表 `selectList`。 |
| 数据服务 API 统计分页 | `queryApiStats()` 走 `countApiStats/selectApiStatsPage`，属于正常分页聚合读取。 |
| 数据服务访问日志列表 | `queryAccessLogs()` 使用 `accessLogListQuery()` 字段级 `select`，只覆盖表格和详情抽屉复用字段，不读取 `systemLog/logObjectBucket/logObjectKey/logArchiveError` 等完整日志或对象归档字段。 |
| 完整调用日志抽屉 | `InvocationLogDrawer` 通过独立 `/invocation-logs/data-services/{id}` 链路读取完整日志；后端先读取日志指针字段，历史兜底才读取 `systemLog/logArchiveError`。 |
| 前端访问行为 | `/data-service-metrics` 与 `/data-service-metrics/access-logs` 均从 build-nginx 入口访问；页面当前项目上下文正确，console warn/error 为 0。 |
