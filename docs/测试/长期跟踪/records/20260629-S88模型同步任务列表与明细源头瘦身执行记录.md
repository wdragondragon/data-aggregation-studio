## 问题确认

| 编号 | 模块 | 现象 | 真实存在 | 是否需要修复 |
|---|---|---|---|---|
| S88-MS-001 | 数据资产/模型同步任务列表 | `ModelSyncTaskService.list()` 使用 `selectPage` 未显式 `.select(...)`，读取 `datasource_*`、`batch_no`、`source`、`created_by`、`started_at`、`finished_at`、`last_error` 等列表不展示字段 | 是 | 是 |
| S88-MS-002 | 数据资产/模型同步任务明细 | `listItems()` 先通过 `selectById` 完整读取任务做访问校验，随后明细分页也未显式选择表格字段 | 是 | 是 |

根因：

- 模型同步任务实体没有超大 JSON 字段，所以不是高危大字段事故，但仍违反长期目标中的“表格只取展示字段；详情按 id 才取完整数据”规则。
- 明细列表只需要任务 `id/tenantId/projectId` 做访问校验，不需要任务数据源快照、计数、错误信息和时间字段。
