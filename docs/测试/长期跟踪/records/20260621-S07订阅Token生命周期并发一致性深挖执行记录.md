## 修复摘要

- 三类开放调用 token 校验成功后仍保留原返回订阅对象，但刷新 `lastUsedAt` 时不再用整行 `updateById`。
- 新增三条单元回归，覆盖数据服务、数据接入、协议转换，防止后续把局部刷新退化回整行更新。
- S07 API 探针覆盖三类服务的 token 创建、轮换、禁用、启用和开放调用状态变化。
