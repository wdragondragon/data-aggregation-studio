## 问题确认

| 编号 | 模块 | 现象 | 真实存在 | 是否需要修复 |
|---|---|---|---|---|
| S90-DS-001 | 数据服务/服务列表 | `DataServiceService.list()` 的 `.select(...)` 包含 `tenantId/deleted/createdBy/serviceType/datasourceId/modelId/requestMethod/responseType/cacheEnabled/tokenRequired/defaultSubscriptionName/webserviceEnabled` 等表格不展示字段 | 是 | 是 |
| S90-DI-001 | 数据接入/服务列表 | `DataIngestionService.list()` 的 `.select(...)` 包含 `tenantId/deleted/createdBy/requestFormat/payloadMode/dataNodePath/datasourceId/datasourceTypeCode/modelId/maxBatchSize/tokenRequired/defaultSubscriptionName/webserviceEnabled` 等表格不展示字段 | 是 | 是 |
| S90-UI-001 | 数据服务/数据接入列表写后刷新 | 两个列表页删除服务后直接调用 `loadServices()` 重拉整个列表 | 是 | 是 |

根因：

- 早期列表视图同时承载列表行和部分详情基础字段，列表源查询按“操作可能复用”的思路保留了过多字段。
- 删除动作没有沿用局部移除当前行的刷新收敛模式。
- 发布/下线等列表行 patch 已依赖完整接口返回，前端 patch 白名单也应只接收表格实际需要字段，避免把详情字段重新塞回列表行。
