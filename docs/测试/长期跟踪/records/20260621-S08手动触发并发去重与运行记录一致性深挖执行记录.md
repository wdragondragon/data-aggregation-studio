## 修复摘要

- 三类手动触发入口改为带 cluster guard 的状态触发方法，统一把锁忙和已有活跃运行映射为可理解的 `BAD_REQUEST`。
- `ClusterLockService` 新增非重入锁能力，避免同一 Server 实例内多个请求因相同 `owner_id` 重入同一业务锁。
- 手动触发成功后保留 10 秒锁租约，不在方法返回时立即释放，防止快速完成的工作流首节点或短任务被同一批次/双击再次触发。
- 对数据库死锁、锁等待超时、SQLite database locked 等锁竞争场景返回锁忙，而不是泄漏 500。
- 自动化脚本保留所有长期运行数据，只新增可追溯的运行记录和元数据库对账证据。
