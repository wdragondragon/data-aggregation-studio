## 问题确认

| 编号 | 模块 | 现象 | 真实存在 | 是否需要修复 |
|---|---|---|---|---|
| S85-LOG-001 | 开放调用完整日志 | 数据服务、数据接入、协议转换“完整日志”抽屉只需要归档指针或历史兜底日志，却先读取访问日志整实体 | 是 | 是 |
| S85-TRACE-001 | 协议转换 Trace | 协议转换调用日志详情只需要权限字段和 Trace 兜底摘要，却用 `selectById` 读取整行 | 是 | 是 |

根因：

- `OpenServiceInvocationLogService.requirePointer()` 对三类访问日志均使用 `selectById`，对象日志已归档可用时也读取 `systemLog`。
- `ProtocolConversionMetricsService.accessLogTrace()` 的权限校验/兜底摘要查询使用 `selectById`，读取了 Trace 不需要的大字段和归档元信息。
