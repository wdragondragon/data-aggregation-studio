## 验收目标

本轮验证“单集群就是只登记一个运行集群的多集群环境”，重点确认：

1. Server 可以作为纯控制面运行，不依赖 DataAggregation 插件目录。
2. 同步数据面调用只由目标 Worker 执行，Worker 不可用时不回退 Server。
3. 异步 Dispatch 只由目标集群领取，目标离线时排队，恢复后继续执行。
4. 同一集群可以通过 SLB 代理扩展多个 Worker，且仍保持单次请求语义。
5. 多运行集群之间按目标集群隔离，不发生自动跨集群故障转移。
6. 访问日志和告警链路不因 OMS 转发重复写入。

本记录是阶段性真实验收证据，不代表 P0-MC-02 已完成。未完成项仍以实施计划的完成定义为准。

- 在未配置 Python 可执行文件时发起助手脚本执行，请求到达 Worker；Worker 返回“Python executable is not configured”类错误，Server 保持 HTTP `500` 和错误语义，没有在 Server 本地执行。
