## 本轮发现

1. `/system?tab=workers` 的 Worker 下发表格只展示 Worker 组、实例状态、心跳、绑定状态等字段，但后端 `SystemManagementService.listProjectWorkers()` 查询 `worker_lease` 时未使用 `select(...)` 裁剪字段，会读取 `capabilitiesJson` 后在视图组装阶段丢弃，属于“表面轻、内里重”。
2. `/system` 除用户管理外，租户、项目、租户成员、项目成员、申请/邀请、Worker 下发、资源共享、注册登记的保存/审批/删除操作仍通过通用 `wrapSave/confirmDelete` 执行 `authStore.refreshProfile()` 和 `loadCurrentTab()`，导致单行变更后重拉当前 tab；资源共享 tab 还会顺带重拉项目列表和资源选项。

## 修复内容

1. `SystemManagementService.listProjectWorkers()` 查询 `worker_lease` 时从源头只选择页面需要的 Worker 标识、实例、节点、状态和心跳字段，排除 `capabilitiesJson`。
2. `SystemView.vue` 新增本地行级 patch 工具：
   - 租户、项目保存/删除直接更新当前表格行，保留必要 profile 刷新以同步顶部组织上下文。
   - 租户成员、项目成员、申请/邀请、注册登记保存/审批/删除按返回值局部更新当前行或删除当前行，仅当影响当前登录用户时刷新 profile。
   - Worker 绑定保存后用当前行实例信息补齐绑定状态，解绑后仅更新/移除当前 Worker 行。
   - 资源共享保存/删除只刷新资源共享分页列表，不再重拉项目列表和资源选项。
