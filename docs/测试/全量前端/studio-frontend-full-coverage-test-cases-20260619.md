## 判定规则

- `PASS`：页面或主链路按预期工作，或错误场景返回可理解业务提示。
- `FAIL`：页面白屏、路由不可达、保存/发布/执行主链路失败、错误提示不可理解、数据写入错误、权限绕过、控制台 Studio error、测试数据无法清理。
- `BLOCKED`：依赖外部运行环境，例如当前项目没有可用 Worker，导致触发/运行类验证无法继续。
- `需要修复`：所有 `FAIL`；`BLOCKED` 仅在目标测试环境应当内置该前置能力时需要补环境或修复。
