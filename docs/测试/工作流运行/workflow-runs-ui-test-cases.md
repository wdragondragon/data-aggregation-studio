# 工作流运行模块 Web 测试用例

## 1. 测试目标

本文档用于记录 Web 端“工作流运行”模块的基础回归与历史冒烟用例，重点覆盖：

- 页面路由与项目上下文展示
- 筛选区渲染
- 汇总卡片渲染
- 空列表与分页空态渲染

## 2. 测试环境

| 项目 | 说明 |
| --- | --- |
| 前端 | `http://127.0.0.1:5173` |
| Studio Server | `http://127.0.0.1:18080` |
| Studio Worker | `http://127.0.0.1:18081` |
| 数据库 | SQLite：`backend/studio-test/target/test-runtime/web-smoke.db` |
| 登录账号 | `admin / admin123` |
| 当前租户 | `Default Tenant` |
| 当前项目 | `Default Project` |

## 3. 用例列表

| 编号 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| WR-UI-001 | 页面可进入 | 登录后访问 `/runs` | 页面标题为“工作流日志”，上下文显示正常 |
| WR-UI-002 | 筛选区渲染 | 打开页面 | 工作流、状态、开始/结束时间、查询/重置按钮完整显示 |
| WR-UI-003 | 汇总卡片渲染 | 打开页面 | 运行次数、失败数、运行中节点、成功节点卡片正常显示 |
| WR-UI-004 | 空态列表渲染 | 初始化项目无工作流运行记录 | 列表展示“暂无数据”，分页显示总数 `0` |
| WR-UI-005 | 浏览器稳定性 | 执行 WR-UI-001 至 WR-UI-004 | 浏览器控制台无 `error` / `warn`，页面无异常跳转 |

## 4. 通过标准

- WR-UI-001 至 WR-UI-005 全部通过。
- 在无运行记录的情况下，页面必须展示清晰空态且筛选区可继续使用。
