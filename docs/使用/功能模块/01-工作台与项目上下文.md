# 工作台与项目上下文

## 模块定位

工作台负责承载登录后的项目上下文、总览指标、能力入口和访问申请流程。Studio 的大多数业务资产都归属到租户和项目，用户进入项目后才能使用数据源、模型、采集、服务和质量能力。

## 适用角色

- 平台管理员：查看租户、项目和系统能力概况。
- 项目管理员：确认项目资产、成员和运行状态。
- 普通成员：进入已授权项目，访问自己有权限的业务模块。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 总览 | `/dashboard` | 查看当前项目概览、资产统计和任务状态 |
| 能力矩阵 | `/catalog` | 查看当前环境已启用的数据源和插件能力 |
| 访问申请中心 | `/access-center` | 无项目权限时提交加入项目申请 |

## 核心概念

- 租户：平台最高隔离单元。
- 项目：租户下的工作空间，业务数据源、模型、任务、服务和日志都归属到项目。
- 当前项目：页面顶部选中的项目上下文，决定列表数据和可操作资产范围。
- 权限刷新：项目审批或角色变更后，需要刷新权限或重新登录才能看到最新菜单。

## 常用操作流程

1. 登录 Studio。
2. 在顶部确认当前租户和项目。
3. 如果没有项目，进入访问申请中心提交申请。
4. 项目管理员审批后，刷新权限并进入总览页。
5. 从左侧菜单进入数据资产、数据采集、数据服务等功能域。

## 关键配置说明

- 菜单可见性由登录态、项目上下文和角色共同决定。
- 没有项目权限时，业务菜单通常不可见，系统会引导到访问申请中心。
- 总览指标来自当前项目，不代表全租户或全平台数据。

## 验收与排障建议

- 登录后看不到业务菜单：确认账号是否加入项目，角色是否包含业务权限。
- 项目刚审批通过仍不可见：点击刷新权限或重新登录。
- 总览数据与预期不一致：确认顶部选择的租户和项目是否正确。
