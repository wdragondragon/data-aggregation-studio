# 数据采集任务

## 模块定位

数据采集任务定义从源端读取、经过字段映射或转换、写入目标端的同步链路。任务底层由 DataAggregation Reader、Transformer、Writer 插件执行，Studio 负责可视化配置、上线、触发、运行记录和日志查看。

## 适用角色

- 数据集成实施人员：配置和维护采集任务。
- 项目管理员：审核任务上线、调度和运行状态。
- 运维人员：排查任务失败、性能和 Worker 问题。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 字段映射规则 | `/field-mapping-rules` | 维护可复用字段映射规则 |
| 采集任务 | `/collection-tasks` | 新建、编辑、上线和触发采集任务 |
| 采集运行记录 | `/collection-task-runs` | 查看任务运行状态和日志 |
| 运行指标 | `/run-metrics` | 查看采集任务运行指标 |

## 核心概念

- Reader：源端读取插件。
- Writer：目标端写入插件。
- Transformer：可选的数据转换插件。
- 字段映射：源字段到目标字段的映射关系。
- 运行参数：Reader/Writer 的分页、批量、HTTP Header、SOAP Envelope 等配置。

## 常用操作流程

1. 准备源数据源、目标数据源、源模型和目标模型。
2. 新建采集任务，选择源端和目标端。
3. 配置 Reader/Writer 运行参数。
4. 配置字段映射和转换规则。
5. 保存草稿，检查生成配置。
6. 上线任务，手动运行或交给工作流调度。
7. 在运行记录中查看状态、日志和指标。

## 关键配置说明

- 数据库采集关注主键、增量条件、批大小和写入模式。
- HTTP REST/XML/SOAP 采集关注协议模式、Header、Query、Body、分页和响应解析路径。
- SOAP Writer 数组模式需要明确目标数据节点，字段映射变化后应检查 XML 预览。
- 批量大小控制单次 Writer 写入的数据量，需结合目标端吞吐和接口限制设置。

## 验收与排障建议

- 任务长期运行中：检查 Worker 在线状态、任务日志和运行队列。
- 写入数量不一致：检查过滤数、失败数、字段映射和目标写入规则。
- HTTP/SOAP 调用失败：检查 Token、Content-Type、Envelope、SOAP Fault 和响应状态校验。
- 重复运行结果异常：确认目标写入模式是追加、覆盖还是更新。
