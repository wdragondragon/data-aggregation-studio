# 数据开发

## 模块定位

数据开发提供脚本目录、脚本编辑和在线执行能力，用于查询验证、测试数据准备、问题排查和工作流脚本节点复用。当前常用脚本类型以 SQL 为主，也可承载 Java 等脚本能力。

## 适用角色

- 数据开发人员：编写和执行 SQL 脚本。
- 数据集成实施人员：准备测试数据、验证采集结果。
- 运维人员：通过 SQL 或脚本排查运行问题。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 数据开发 | `/data-development` | 管理脚本目录、编辑脚本、选择数据源执行 |

## 核心概念

- 脚本目录：按项目管理脚本文件和分组。
- 执行数据源：脚本运行时绑定的数据源上下文。
- 执行记录：保存脚本执行状态、耗时、返回结果和错误信息。
- 工作流复用：脚本保存后可作为工作流节点资源。

## 常用操作流程

1. 进入“数据开发 / 数据开发”。
2. 新建或选择脚本目录。
3. 编写 SQL 或其他脚本内容。
4. 选择执行数据源。
5. 执行脚本并查看结果。
6. 将可复用脚本保存，供工作流编排引用。

## 关键配置说明

- SQL 脚本必须选择正确的数据源，避免误操作其他环境。
- 初始化、建表、测试数据准备等脚本建议保留时间戳和用途说明。
- 查询大表时建议增加分页或限制条件，避免页面返回过大。
- 写入或清理脚本执行前应确认项目和数据源上下文。

## 验收与排障建议

- SQL 执行失败：检查数据源连接、SQL 方言、权限和表名大小写。
- 查询结果为空：确认筛选条件、当前数据源和测试批次字段。
- 页面响应慢：减少返回字段和行数，或改用聚合查询确认结果。
