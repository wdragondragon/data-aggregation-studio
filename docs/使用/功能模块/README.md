## 阅读建议

- 首次接入项目时，先阅读“工作台与项目上下文”“数据源管理”“模型中心与模型同步”。
- 配置同步链路时，按“数据源管理 -> 模型中心 -> 数据采集任务 -> 运维中心与日志”的顺序阅读。
- 发布开放服务时，按“模型中心 -> 数据服务/数据接入服务/协议转换服务 -> 运维中心与日志”的顺序阅读。
- 排查运行问题时，优先查看对应模块的“验收与排障”章节，再查看运维日志和统一告警中心文档。
