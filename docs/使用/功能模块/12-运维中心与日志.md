# 运维中心与日志

## 模块定位

运维中心与日志能力用于查看 Worker 状态、任务运行、服务调用、异常摘要和归档日志。它是排查采集任务、工作流、数据服务、数据接入服务和协议转换服务问题的统一入口。

## 适用角色

- 运维人员：查看运行状态、日志和异常。
- 项目管理员：确认项目任务和开放服务运行情况。
- 开发实施人员：通过日志定位配置、协议和数据问题。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 运维中心 | `/ops-center` | 查看 Worker、队列、服务异常和运行概览 |
| 告警中心 | `/alerts` | 配置项目级告警，确认和关闭事件，查看通知投递 |
| 采集运行记录 | `/collection-task-runs` | 查看采集任务日志 |
| 工作流运行实例 | `/runs` | 查看工作流和节点日志 |
| 数据服务监控 | `/data-service-metrics` | 查看数据服务调用日志 |
| 接入服务监控 | `/data-ingestion-metrics` | 查看数据接入调用日志 |
| 协议转换调用日志 | `/protocol-conversions/access-logs` | 查看协议转换四阶段 trace |

## 核心概念

- 主程序日志：Server/Worker 普通运行诊断日志。
- 采集运行日志：按采集任务运行记录归档的过程日志。
- 开放调用日志：按一次数据服务、数据接入服务或协议转换调用归档。
- MDC 隔离：通过请求或运行上下文隔离专用日志。
- 对象存储归档：大日志和调用级详情可归档到 OSS/MinIO。

## 常用操作流程

1. 先在对应业务页面确认状态和错误摘要。
2. 进入运行记录或调用日志查看当前请求/任务的详情。
3. 对采集和工作流问题，查看节点或插件日志。
4. 对开放服务问题，查看请求参数、目标状态、业务错误和归档日志。
5. 对协议转换问题，优先查看四阶段 trace。
6. 如页面信息不足，再查看 Server/Worker 主程序文件日志。

## 关键配置说明

- Server 和 Worker 是独立进程，分别有主程序日志。
- 主程序文件日志用于普通诊断，调用级详细日志由业务归档保留。
- 数据服务、数据接入服务、协议转换服务按开放调用维度生成日志。
- 采集任务日志按运行记录维度生成，便于和任务指标对应。

## 验收与排障建议

- 页面没有日志：确认日志归档配置、对象存储配置和服务运行环境。
- 任务无 Worker 执行：检查 Worker 在线、Worker 组、队列和任务分发状态。
- 开放调用失败：先看访问日志状态，再看归档日志或四阶段 trace。
- 控制台有日志但文件没有：确认是否属于被专用 MDC 捕获的调用级日志。
