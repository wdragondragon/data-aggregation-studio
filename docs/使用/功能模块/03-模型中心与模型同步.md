# 模型中心与模型同步

## 模块定位

模型中心用于管理数据源中的可操作对象，例如数据库表、文件、消息主题和 HTTP/SOAP 结构。采集任务、数据服务、数据接入服务和质量任务都依赖模型字段和模型元数据。

## 适用角色

- 数据资产管理员：维护模型资产、字段、业务元数据和血缘。
- 数据集成实施人员：为采集任务和服务发布准备源模型、目标模型。
- 数据治理人员：查看模型统计、字段信息和资产分布。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 元模型中心 | `/metadata` | 管理动态元模型和表单结构 |
| 模型中心 | `/models` | 查询、同步、查看和维护模型 |
| 模型统计 | `/statistics` | 查看模型资产统计 |

## 核心概念

- 元模型：决定数据源、模型、字段和运行参数的动态表单结构。
- 模型：数据源中的具体对象，例如一张表或一个 HTTP 模型。
- 字段：模型内可映射、可查询、可写入的列或节点。
- 父节点：用于 XML/SOAP/复杂对象字段路径表达。
- 模型同步：从数据源发现对象和字段，并写入 Studio 模型中心。

## 常用操作流程

1. 确认数据源已创建、启用并纳入管理。
2. 进入模型中心，选择数据源执行同步。
3. 对首次接入可同步全部模型，生产环境建议同步选中模型。
4. 打开模型详情，检查字段、类型、主键、父节点和样例数据。
5. 如源端结构变化，重新同步对应模型。

## JSON 批量导入字段

- 新建和编辑模型时，字段区域均支持选择 UTF-8 JSON 文件或粘贴 JSON 内容。JSON 可以直接使用字段数组，也可以使用只包含 `columns` 的包装对象。
- 新建模型导入会整体替换表单中的当前字段；已有手工字段时需要确认覆盖。
- 编辑模型导入提供“原位合并”“导入字段优先”和“全量替换”三种方式。默认使用原位合并：同名字段在原位置整行覆盖，未匹配旧字段保留，新字段追加到末尾。
- 字段名去除首尾空格后进行大小写敏感匹配，因此 `id` 与 ` id ` 匹配，`id` 与 `ID` 不匹配；最终字段名保持 JSON 中的原值。
- 导入弹窗会显示覆盖、新增、保留、删除和最终字段数。历史模型存在重复字段名时不能执行合并，但可以使用全量替换清理重复字段。
- 导入结果只写入当前编辑表单，必须继续点击“保存”才会持久化；取消模型编辑不会修改已保存模型。

## 关键配置说明

- 数据库模型应重点检查主键、字段类型、可空性和更新时间字段。
- HTTP/SOAP 模型应重点检查 Endpoint、协议模式、字段名和父节点路径。
- 目标模型用于写入时，应确认字段映射名称与写入服务或 Writer 参数一致。
- 字段父节点会影响 SOAP/XML 的解析、模板生成和数组节点判断。

## 验收与排障建议

- 模型字段缺失：重新同步模型，并确认账号有查看元数据权限。
- 预览失败：检查数据源连接、SQL 权限、表名大小写和网络访问。
- SOAP/XML 字段取不到值：确认父节点路径和响应实际节点一致。
