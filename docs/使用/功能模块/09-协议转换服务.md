# 协议转换服务

## 模块定位

协议转换服务用于用一种对外入口协议包装下游目标接口：调用方按入口协议请求并获得入口协议响应，系统内部按配置转换为目标 HTTP JSON、HTTP XML 或 SOAP 1.1/1.2 请求并转发。它适合在调用方协议与目标服务协议不一致时做轻量网关式转换。

## 适用角色

- API 集成实施人员：配置协议转换和字段映射。
- 服务维护人：把现有数据服务或数据接入服务转换为另一种调用形态。
- 运维人员：查看协议转换访问日志、四阶段 trace 和目标调用错误。

## 入口路径

| 页面 | 路由 | 用途 |
|---|---|---|
| 协议转换服务 | `/protocol-conversions` | 新建、编辑、发布和调试协议转换 |
| 协议转换调用日志 | `/protocol-conversions/access-logs` | 查看开放调用日志和四阶段转换过程 |

## 核心概念

- 入口协议：调用方提交给协议转换服务的协议和最终响应格式。
- 目标协议：协议转换服务转发到下游目标端的协议和 Body 格式。
- FIELD_MAPPING：按字段映射解析源报文并生成目标报文。
- RAW_MESSAGE_FIELD：把原始报文经转换器处理后写入目标字段。
- BODY_BRIDGE：不做细字段映射，直接将入口 Body 转换为目标协议 Body。
- 四阶段 trace：对外原请求、目标请求生成、目标原响应、对外响应生成。

## 常用操作流程

1. 新建协议转换服务，填写基础信息。
2. 配置入口协议、目标协议、目标 URL 和目标认证 Header。
3. 选择转换模式，并配置字段映射、固定字段、透传或桥接规则。
4. 配置目标 SOAP 时，确认 SOAP 版本、命名空间、Operation 和实体节点。
5. 在调试确认页提交样例请求，查看业务响应和四阶段 trace。
6. 创建订阅 Token 并发布服务。
7. 调用开放入口，并在调用日志中查看目标状态和脱敏请求详情。

## 关键配置说明

- 开放调用响应只返回业务响应体，不暴露目标请求详情。
- 调试接口可以展示脱敏后的目标请求，用于联调。
- 透传先执行，页面配置的 Header、Query、Body 参数会追加并覆盖同名透传参数。
- SOAP 目标配置应明确命名空间、Operation、请求实体和数组数据节点。

## 验收与排障建议

- 返回数据未按参数过滤：检查目标请求生成阶段的字段名、透传和覆盖关系。
- 目标返回 SOAP Fault：检查目标 Token、SOAP 版本、Envelope 和 Operation。
- BODY_BRIDGE 返回结构异常：查看目标请求生成和对外响应生成阶段的 Body 结构。
- 日志排查时优先看四阶段 trace，再查看完整归档日志。
