# 数据服务模块测试用例

## 1. 测试目标

本文档用于交接数据服务模块的功能测试，覆盖服务创建、字段解析、参数配置、发布、订阅、调试、开放调用、缓存、监控统计、访问日志、权限与异常场景。

测试范围包含：

- 数据服务列表与查询
- 数据服务新增、编辑、保存、删除
- 数据表模式服务开发
- SQL 语句模式服务开发
- 请求参数、返回参数、发布参数映射
- 服务发布、下线、重新发布
- 订阅 Token 创建、展示、停用、启用、同名刷新
- 接口调试、调试模板生成、cURL 生成
- 开放 API GET/POST 调用
- 返回结果结构、分页、查询条件、缓存
- 服务监控、API 统计、访问日志下钻
- 权限、项目隔离、异常输入与安全限制

## 2. 测试准备

### 2.1 环境准备

| 项目 | 要求 |
|---|---|
| 前端服务 | 可访问 Studio 前端页面 |
| 后端服务 | Studio Server 正常运行 |
| Worker 服务 | 正常在线，工作流相关联调时可用 |
| 数据库 | 至少存在一个可连接的 MySQL 数据源 |
| Redis | 若验证缓存能力，需要 Redis 可用 |
| 登录账号 | 具备当前租户、当前项目的数据服务管理权限 |
| 浏览器 | Chrome 或 Chromium 内核浏览器 |

### 2.2 测试数据准备

准备一个可用于发布 API 的测试表，表名可使用 `ds_api_customer_test`。

字段建议如下：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| customer_name | varchar | 客户名称 |
| age | int | 年龄 |
| status | varchar | 状态 |
| amount | decimal | 金额 |
| city | varchar | 城市 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

建议准备不少于 25 行数据，保证分页、模糊查询、数值比较、列表查询都有可验证结果。

建议数据特征：

| 场景 | 数据要求 |
|---|---|
| 分页 | 数据总量大于 10 行 |
| 精确查询 | 至少存在状态为 `ACTIVE`、`DISABLED` 的记录 |
| 模糊查询 | 至少存在多个名称包含相同关键词的记录 |
| 数值比较 | 年龄、金额存在大于、小于、等于边界值 |
| 列表查询 | 城市字段存在多个可枚举值 |
| 时间查询 | 创建时间跨多天 |

### 2.3 通用校验规则

| 校验项 | 期望 |
|---|---|
| 项目隔离 | 当前项目只能看到当前项目的数据服务 |
| 必填项 | 空值保存时应有明确提示 |
| 分页 | 列表分页切换后数据正确，序号和总数正确 |
| 失败提示 | 接口失败时页面展示可理解的错误信息 |
| 敏感信息 | 订阅 Token 只在创建或刷新时明文展示 |
| 开放调用 | 未携带有效 Token 不允许访问数据 |
| 监控口径 | 后台调试不计入开放 API 监控 |

## 3. 接口测试用例

| API-005 | 新增数据表模式服务 | 数据源和模型存在 | 调用 `POST /api/v1/data-services` 保存数据表模式服务 | 保存成功，返回服务 id，默认包含分页参数 |
| API-006 | 新增 SQL 模式服务 | 数据源存在 | 使用合法 `select` SQL 保存服务 | 保存成功，可查看详情 |
| API-007 | 新增服务缺少服务 code | 无 | 保存时不传服务 code | 返回失败，提示服务 code 必填 |

| API-010 | 服务类型为服务代理 | 无 | 保存服务代理类型 | 返回失败或提示当前不可创建该类型 |
| API-011 | 获取服务详情 | 服务已存在 | 调用 `GET /api/v1/data-services/{id}` | 返回基础信息、开发配置、发布配置、参数配置 |
| API-012 | 获取不存在的服务 | 服务 id 不存在 | 调用详情接口 | 返回失败，提示服务不存在 |

| API-014 | 编辑已发布服务 | 服务已发布 | 修改允许编辑的字段后保存 | 保存成功或按规则提示需要重新发布 |
| API-015 | 删除草稿服务 | 服务为草稿 | 调用 `DELETE /api/v1/data-services/{id}` | 删除成功，列表不再显示 |
| API-016 | 删除已发布服务 | 服务已发布 | 调用删除接口 | 按规则阻止删除或先下线后删除，提示明确 |
| API-017 | 跨项目查询服务 | 当前项目 A，服务属于项目 B | 使用项目 B 的服务 id 查详情 | 返回无权限或服务不存在 |
| API-018 | 未登录访问管理接口 | 无登录态 | 调用任意管理接口 | 返回未认证 |
