# 统一日志系统接入指引

## 目标

Studio 日志分为两类：

- 异步任务日志：采集任务、质量任务、工作流等有 `run_record` 的任务，按运行记录归档。
- 同步开放调用日志：数据服务、数据接入服务、协议转换服务等一次 HTTP/SOAP 调用就是一个日志上下文，按访问日志归档。

两类日志都复用当前对象存储配置，避免列表接口返回大字段。列表只返回摘要和归档指针，完整日志通过专用日志接口分页读取或下载。

## 存储目录

- 异步任务：`studio/run-logs/yyyy-MM-dd/run-{runRecordId}.log`
- 数据服务开放调用：`studio/invocation-logs/data-services/yyyy-MM-dd/data-service-{requestId}.log`
- 数据接入服务开放调用：`studio/invocation-logs/data-ingestion-services/yyyy-MM-dd/data-ingestion-{requestId}.log`
- 协议转换开放调用：`studio/invocation-logs/protocol-conversions/yyyy-MM-dd/protocol-conversion-{requestId}.log`

`studio/invocation-logs` 可通过 `studio.platform.invocation-log.object-prefix` 调整；对象存储桶、MinIO/OSS 实现和上传方式继续复用 `run-log.object-storage`。

## 同步开放调用接入方式

同步开放调用使用 `OpenServiceInvocationLogSupport` 做 MDC 隔离：

- MDC key：`studioInvocationLogId`
- 每次开放调用生成独立 `requestId`
- 业务入口调用 `invocationLogSupport.open(requestId, domain, jobId)`
- `finally` 中关闭 scope，读取 `scope.content()`
- 使用 `OpenServiceInvocationLogService.archive(...)` 上传归档
- access_log 表保存短摘要 `system_log` 和归档字段

数据接入服务会把 `jobId` 传入 scope，用于捕获 JobContainer 子线程日志。数据服务和协议转换没有 JobContainer 子线程，传 `null` 即可；只要调用链日志带同一个 MDC，就会被本次请求收集。

## access_log 字段要求

同步开放调用类 access_log 表需要包含：

- `request_id`
- `system_log`
- `log_storage_type`
- `log_object_bucket`
- `log_object_key`
- `log_size_bytes`
- `log_charset`
- `log_archive_status`
- `log_archive_error`

`system_log` 只保存摘要，包括服务、订阅、协议、计数、HTTP 状态、错误摘要和耗时。请求头、请求体、目标响应体、控制台日志等完整内容只能写入归档文件。

## API 与页面约束

- 完整日志读取：`GET /api/v1/invocation-logs/{domain}/{accessLogId}`
- 完整日志下载：`GET /api/v1/invocation-logs/{domain}/{accessLogId}/download`
- `domain` 当前支持：`data-services`、`data-ingestion-services`、`protocol-conversions`
- 页面列表禁止直接展示完整归档正文。
- 页面详情可展示 `system_log` 摘要，并提供“完整日志”入口。
- 完整日志抽屉按 64KB 分页读取，大日志通过下载查看。

## 脱敏与截断

日志归档前会统一脱敏：

- JSON 字段：`password`、`accessKey`、`secretKey`、`token`、`privateKey`、`apiKey`、`authorization`、`cookie`
- key/value 形式的同名敏感字段
- Header 名称包含 `token`、`authorization`、`cookie`、`secret`、`key`、`password` 时，值显示为 `******`

归档正文默认最多保留 `maxLogChars`；单个 body 预览默认最多保留 `maxBodyChars`。超限内容会带截断提示。

## 后续模块接入建议

数据质量、数据开发、数据资产同步任务接入时先判断是否有 `run_record`：

- 有调度和运行记录：使用异步任务日志模式，挂到 `run_record`。
- 没有运行记录、一次请求即时完成：使用同步开放调用日志模式，建立对应 access_log 表和 `domain`。

新增同步 domain 时需要同步：

- access_log 实体和 DTO 增加归档字段。
- `OpenServiceInvocationLogService` 增加 domain 常量和访问日志指针读取。
- 前端列表使用 `InvocationLogDrawer`。
- 初始化 SQL 和 update SQL 增加归档字段。
