# Studio 打包部署交付物

## 1. 交付目录

~~~text
data-aggregation-studio-<release-version>/
  gateway-service.jar
  front.zip
  studio-server-<release-version>-exec.jar
  studio-worker-<release-version>-exec.jar
  aggregation-plugins.zip
  studio-flink-<release-version>-connector-remote-upload.jar
  sql/
    init/
      schema-mysql.sql
      data-mysql-base.sql
      data-mysql-builtin.sql
      data-mysql-runtime-options.sql
    update/
      <本版本新增的增量SQL>
~~~

完成后压缩整个目录：

~~~text
data-aggregation-studio-<release-version>.zip
~~~

## 2. 打包方法

### 2.1 Server、Worker 和 Flink connector

~~~bash
cd DataAggregation/data-aggregation-studio/backend
mvn -pl studio-server,studio-worker,studio-flink -am clean verify
~~~

复制：

~~~text
studio-server/target/studio-server-<release-version>-exec.jar
studio-worker/target/studio-worker-<release-version>-exec.jar
studio-flink/target/studio-flink-<release-version>-connector-remote-upload.jar
~~~

只交付 `connector-remote-upload.jar`，不交付、不安装、不启动 `studio-flink` 可执行 JAR。

### 2.2 Gateway

~~~bash
cd <cloud-parent-root>
mvn -pl gateway-service -am clean package
~~~

复制 `gateway-service/target/gateway-service.jar`。

### 2.3 fronted

~~~bash
cd DataAggregation/data-aggregation-studio/frontend
npm ci
npm run build:web
~~~

前端 base 固定为：

~~~typescript
base: '/dfs/data-aggregation-studio/'
~~~

把 `apps/web/dist/` 里面的内容直接压缩为 `front.zip`。解压后第一层必须直接包含：

~~~text
index.html
assets/
~~~

### 2.4 Aggregation 插件

打包成出aggregation完整插件包。
~~~bash
cd DataAggregation
bash package_all/packe_move.sh
bash package_all/packe_move_transformer.sh
~~~

将aggregation组织成oss版本控制存放的形式。
~~~bash
cd DataAggregation
bash package_all/build_plugin_repository.sh \
  --all \
  --aggregation-home package_all/aggregation \
  --output-root /tmp/release/aggregation-plugins \
  --channel production \
  --release <plugin-release>
~~~

按照以上命令输出最终输出到`/tmp/release/aggregation-plugins`，将其打包成aggregation-plugins.zip
